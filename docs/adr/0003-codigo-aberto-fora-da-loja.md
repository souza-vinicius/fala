# Código aberto, fora da loja

Status: accepted

O Fala é um projeto de código aberto. A pessoa instala por um download ou compilando o código. Não há instalação pela Mac App Store.

## Opções consideradas

- Publicar na Mac App Store. A sandbox da loja bloqueia a API de acessibilidade. Sem essa API, a cola e a detecção de campo de senha ficam mais fracas. A loja também pede conta da Apple para instalar.
- Código fechado com download direto. Fica de fora porque o projeto é público.

## Consequências

- A cola e a detecção de campo de senha podem usar a API de acessibilidade.
- A licença do código, enquanto outra não for nomeada, é Apache 2.0, a mesma do Gemma 4.
- Atualização pela loja não existe. A busca automática de atualização continua fora de escopo.
